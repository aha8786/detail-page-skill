## 5. 합격 기준 (7단계 자체 테스트용)

렌더된 PNG를 **직접 열어** 아래를 대조한다. 코드만 보고 통과시키지 않는다.

### 규격 — 전부 수치 일치
```
[ ] 5개 PNG 폭 전부 정확히 1220px
[ ] 높이  01:2000  02:1206  03:2572  04:2480  05:1290   (DPR2 기준)
[ ] 5장 이어붙였을 때 이음매 색 어긋남 없음
[ ] 좌우 여백 48px (DPR2 96px) 일정, 사진만 풀블리드
[ ] package 사진만 인셋 336px (DPR2 672px)
[ ] point 사진 비율 1 : 0.672 ± 0.01
```

### 타이포 — 잉크높이 실측
```
[ ] hook 대제목 잉크 73 ± 3
[ ] hook 서브카피 잉크 16 ± 2
[ ] opener 한글 잉크 63 ± 3
[ ] point 대제목 잉크 48 ± 2
[ ] point 본문 잉크 22 ± 2
[ ] package 본문 잉크 20 ± 2
[ ] 대비비 hook ≥ 3:1 / point ≥ 2:1
[ ] 폰트 폴백 없음 (스퀘어 고딕 적용 확인 — 잉크÷pitch ≥ 0.9)
[ ] point 대제목 정확히 2줄 / 본문 3줄
[ ] 줄바꿈이 단어 중간을 끊지 않음
```

### 색·형태
```
[ ] 차콜/크림/웜그레이 3색 외 혼입 0
[ ] 본문 블록 상하 여백 동일 (point 23.5/23.5 · package 35.7 ×3)
[ ] 어절 중간 끊김 0, 줄 끝 쉼표 0, 한 줄 안 문장 전환 0

**사진 (TOOL v0.6)**
[ ] 7개 사진 전부 바로 옆 멘트의 내용과 일치
[ ] 크롭·블러 후에도 피사체 식별 가능
[ ] 텍스트가 피사체를 가리지 않음
[ ] 상품이 프레임 한가운데. 가장자리 걸림 0
[ ] 배경 구조물(테두리·선반)이 화면을 먹지 않음
[ ] 배지=원형 / 강조바=각짐 / 필=pill / 하이라이트=각짐
[ ] 정렬 — hook·opener·package 가운데 / point 왼쪽
[ ] 면책 회색 #828282, 크기는 약속과 동일
```

### 법규 — 전수 검사
```
[ ] 4장 금지 목록 전 항목 0건
[ ] 택배사·아이스박스·아이스팩·소요일·유통기한 0건
[ ] 활·생물·냉장·자연산·논 0건
[ ] 무첨가 강조 0건
```

### 기획 일치
```
[ ] 블록 순서 01→05 일치
[ ] 하이라이트 비중 point1 40% / point2 39% (±5%p)
[ ] 배지 라벨 전부 4글자
