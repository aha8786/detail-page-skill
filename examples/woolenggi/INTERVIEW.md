# 🚫 이 상품 전용 금지 표현

**판매 형태(자숙·손질 완료·냉동)상 사실과 다른 표현**
```
✗ 활(活)   ✗ 생물   ✗ 살아있는   ✗ 산 채로
✗ 냉장     ✗ 신선 냉장   ✗ 당일조업(우렁이는 조업 아님)
```

**생산방식 미확인이므로 금지**
```
✗ 자연산   ✗ 야생   ✗ 논에서 기른   ✗ 청정 논   ✗ 양식
→ 쓸 수 있는 것은 `국내산` / `담양` 뿐
```

**영양 근거를 성분명만으로 정했으므로**
```
✗ 100g당 단백질 Xg   ✗ 풍부 / 가득 / 많이   ✗ 고단백 / 저지방
✗ ~에 도움이 되며     ✗ 활력 / 보충 / 원기 / 보양
```

**배송·물류 정보 — 이미지에서 영구 제외 (TOOL.md 6-9절)**
```
✗ 택배사명       ✗ 배송 소요일     ✗ 아이스박스 / 스티로폼
✗ 아이스팩 개수   ✗ 제주·도서       ✗ 배송비 / 무료배송
✗ 주문 마감 시각  ✗ 발송 요일       ✗ 유통기한 / 소비기한
✗ 교환·반품·환불
```
전부 플랫폼 입력 폼이 처리한다. 이미지에 넣으면 중복이고, 바뀌면 다시 뽑아야 한다.

**`무첨가` 표기 주의**
```
사실   첨가물 없음 (확정)
표기   ✗ 무첨가 / 無첨가 강조     → 타사에 첨가물이 있는 것처럼 오인 우려
       ✓ 다른 것 넣지 않고 삶기만 했습니다   → 사실 서술, 안전
```

**자료 01에서 그대로 쓰면 안 되는 문구**
```
⚠ 이 가격에 국내산 우렁이살은 정말 보기 어렵습니다
   → 근거 없는 희소성·가격 우위 주장. 삭제 또는 사실 기반으로 교체

⚠ 활용도 최고
   → `최고` 는 과장 표현. `요리에 바로` 등으로 교체

✅ 오동통하게 살 오른     관능 표현. 사용 가능
✅ 쫄깃한                관능 표현. 사용 가능
✅ 손질 끝 / 삶기도 끝     사실. 사용 가능
```

# hook 배지 3개 (확정)

```
배지 1   담양산지    ← 원산지
배지 2   자숙완료    ← 가공
배지 3   소량포장    ← 포장
```

시간 순서: 어디서 왔나 → 어떻게 처리했나 → 어떻게 담았나.
**전부 4글자** — REF-01 규칙 충족. 글자 수 불일치 문제 해소됨.

> Q8 답변이 `국내산(담양)` 이므로 `담양산지` 를 쓴다.
> `국내산` 은 대제목에서 다루므로 배지에서 중복하지 않는다.
