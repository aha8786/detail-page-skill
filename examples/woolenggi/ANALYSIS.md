# 레퍼런스 이미지 분석 기록

레퍼런스 이미지를 하나씩 분석해 누적한다. 목적은 **재현 가능한 블록 규격**을 뽑는 것.
카피를 베끼는 게 아니라 구조·배치·비율·장치를 뽑는다.

모든 수치는 **원본 px**과 **610px 캔버스 환산값**을 함께 적는다. 레퍼런스 폭이 제각각이라 원본 px은 그대로 못 쓴다.
측정 방식: PIL 픽셀 스캔 (흰 글자 잉크 박스의 행/열 런 검출). 눈대중 금지.

## REF-01 | 인트로.png — 히어로/후킹 블록

원본 677 × 1112 px · 환산 배율 k = 610/677 = **0.901**

### 1. 블록 판정

- 대응 블록 ID: **`hook`** (상세페이지 최상단, 첫 화면)
- 하는 일: 3초 안에 "뭘 파는지 + 왜 믿을 만한지"를 동시에 박는다.
- 상품: 국내산 활 돌문어 (수산물 / 신선식품)

### 2. 전체 구조 — 4층 스택

```
┌─────────────────────────┐  y 0
│  ① 여백 (네이비 단색)      │      156px  15.6%
├─────────────────────────┤  y 156
│  ② 텍스트 존             │
│     서브카피 2줄          │      254px  25.4%
│     대제목 2줄            │
├─────────────────────────┤  y 410
│     (간격 50px)          │
│  ③ 신뢰 배지 3개 (원형)    │      137px  13.7%
├─────────────────────────┤  y 597
│  ④ 실물 사진 (지배 영역)   │      405px  40.4%
└─────────────────────────┘  y 1002
```

**총 높이 1002px (610 환산). 비율 1 : 1.64 (세로형).**

핵심: **사진이 40%를 먹는다.** 텍스트 25%, 여백/배지 35%.
수산물은 "실물이 증거"라서 사진에 최대 면적을 준다.

### 3. 배경 — 단색 → 사진 그라데이션 블렌드

| 구간 | y (610) | 내용 |
|---|---|---|
| 단색 네이비 | 0 – 484 | `#000942` 완전 평면. 텍스처 0 |
| 블렌드 | 484 – 577 | 네이비 → 수중 사진, 93px 선형 페이드 |
| 사진 100% | 577 – 1002 | 바닷물 + 갯바위 + 손 + 문어 |

**장치**: 상단은 완전 단색이라 글자 가독성이 100% 확보된다. 사진 위에 글자를 얹지 않는다.
사진은 아래에서 올라와 자연스럽게 이어진다.

**주의**: 배지(y 460–597)가 블렌드 구간(484–577)에 **걸쳐 앉아 있다**.
단색층과 사진층을 물리적으로 꿰매는 역할. 이게 이 블록의 제일 영리한 장치다.

### 4. 텍스트 요소 — 4계층

| 계층 | 내용 | y(610) | 잉크높이 | 글자 pitch | 정렬 | 색 |
|---|---|---|---|---|---|---|
| 서브카피 1 | 쫀득한 식감과 진한 감칠맛 | 156–171 | **16px** | 17.7 | 가운데 | #FFFFFF |
| 서브카피 2 | 당일작업 당일발송으로 신선함까지! | 179–195 | **16px** | 17.7 | 가운데 | #FFFFFF |
| 대제목 1 | 국내산 | 239–311 | **73px** | 74.8 | 가운데 | #FFFFFF |
| 대제목 2 | 활 돌문어 | 337–410 | **74px** | 74.8 | 가운데 | #FFFFFF |
| 배지 라벨 | 당일조업 / 산지직송 / 생물발송 | 557–571 | **15px** | 16 | 가운데 | #FFFFFF |

**행간(pitch, 줄 시작점 간 거리)**
- 서브카피 1→2: **23px** (잉크높이의 1.44배 — 촘촘)
- 대제목 1→2: **98px** (잉크높이의 1.33배 — 더 촘촘, 덩어리감)

**크기 대비비 = 73 : 16 = 4.6 : 1**
이게 이 블록의 핵심 수치다. 대제목이 서브카피의 **4.6배**.
이 정도 벌려야 스크롤 중에도 대제목만 먼저 읽힌다. 3배 미만이면 후킹 실패.

**폰트**
- 잉크높이 ÷ 글자 pitch = **0.96~0.98** → 글자가 정사각 em 박스를 거의 꽉 채운다.
- 일반 고딕(Pretendard 등)은 이 비율이 0.72. **완전히 다른 부류의 폰트.**
- 정체: 헤비 스퀘어 고딕 계열 — `Black Han Sans(검은고딕)` / `GmarketSans Bold` / `여기어때 잘난체` 중 하나.
- 서브카피와 배지 라벨도 **같은 계열**, 한 단계 가벼운 웨이트.
- → 전체 페이지가 **폰트 1종**으로 간다. 제목/본문 폰트 분리 없음.

**자간**: 대제목 글자 사이 잉크 간격 3~9px (pitch 74.8 대비). 붙이지도 벌리지도 않은 기본값.

**그림자**: 대제목에 약한 다크 네이비 드롭섀도. 검출된 다크 픽셀 44개로 매우 옅다.
세기: opacity 약 30%, offset 0/+4px, blur 12px 수준. **있는 듯 없는 듯**이 정답. 진하면 촌스러워진다.

### 5. 원형 신뢰 배지 3개

```
지름         137px
원 간격      22.5px
원 pitch     159.5px  (중심 간)
3개 총 폭    456px    (캔버스 610의 74.8%)
좌우 여백    77px     (각각)
원 y         460 – 597   (중심 y 529)
```

**원 내부 구성 (위→아래)**

| 요소 | y(610) | 크기 |
|---|---|---|
| 상단 패딩 | 460 – 493 | 33px |
| 아이콘 | 493 – 543 | 72 × 50px (선 아이콘) |
| 간격 | 543 – 557 | 14px |
| 라벨 텍스트 | 557 – 571 | 잉크높이 15px |
| 하단 패딩 | 571 – 597 | 26px |

- 아이콘은 원 중심보다 **위쪽**에 배치. 라벨이 아래를 받친다.
- 아이콘 폭 72px = 원 지름의 **53%**. 여백이 충분해 답답하지 않다.
- 아이콘 = **흰색 선(stroke) 아이콘**, 면(fill) 아님. 선 굵기 약 3.5px.
- 라벨은 전부 **4글자**. 길이를 맞춰 3개 원의 시각 무게를 동일하게 만든다. ← 규칙으로 승격

**원 색**: `#0C035C` (배경 `#000942`보다 **더 짙고 더 채도 높은 인디고**).
배경보다 밝게가 아니라 **더 진하게** 눌러서 구분한다. 사진 위에 얹혀도 안 묻힌다.
테두리: 좌상단에 아주 옅은 밝은 블루 림. 유리구슬 같은 입체감.

### 6. 사진

- 구도: **사람 손 두 개가 살아있는 문어를 받쳐 든 클로즈업**
- 손이 하단 좌우 모서리에서 화면 안으로 들어온다
- 문어 머리 정점 y ≈ 612, 다리가 하단 전체로 퍼짐
- 배경: 흐릿한 바닷물 + 갯바위 (얕은 심도, 주피사체만 선명)
- 문어 색 `#B08A78 ~ #EEBDAB` (살아있는 개체의 붉은 갈색), 손 `#F8D1BE`

**이 사진이 하는 일 — 한 컷으로 3가지를 동시에 증명**
1. **살아있음** — 선명한 눈, 탄력 있는 피부, 빨판
2. **크기** — 손과 비교되어 크기가 즉시 읽힘 (자나 숫자보다 강력)
3. **방금 잡음** — 젖은 상태 + 바다 배경

→ **규칙**: 수산물/신선식품 히어로는 **사람 손 + 실물 + 현장 배경**. 스튜디오 누끼컷 아님.
손은 크기 자(scale reference)다. 대체 불가.

### 7. 색 팔레트 — 4색뿐

```
#000942   배경 네이비       (심해, 신뢰, 수산물 정체성)
#0C035C   배지 인디고       (배경보다 진한 톤으로 구분)
#FFFFFF   모든 텍스트·아이콘
사진 원색  문어/손의 따뜻한 살구빛
```

**포인트 컬러가 없다.** 빨강·노랑 강조 0개.
대비를 **오직 크기(4.6배)와 굵기로만** 만든다.

이유: 차가운 네이비 배경 위에서 **문어의 따뜻한 살구빛 자체가 포인트 컬러**로 작동한다.
여기에 빨강을 더하면 사진이 죽는다. 찬 배경 + 따뜻한 피사체 = 보색 대비 완성.

### 8. 시선 흐름

```
1. 대제목 "활 돌문어"     ← 가장 크고 굵음. 무조건 여기 먼저
2. 위로 올라가 "국내산"    ← 바로 위, 같은 크기
3. 서브카피 2줄           ← 위로 더 올라감
4. 아래 배지 3개          ← 원형이라 시선을 잡아챔
5. 사진                  ← 최종 착지, 가장 오래 머무름
```

**흐름이 아래→위→아래인 지그재그.** 대제목이 중앙에 있어서 가운데서 시작한다.
의도적이다. 위에서부터 순서대로 읽게 만들면 서브카피에서 이탈한다.

시선 순서를 만드는 장치: **크기 대비 단독**. 색·화살표·선 안 씀.

### 9. 메시지 구조 — 감각 → 물류 → 신뢰 → 정체 → 증거

| 순서 | 내용 | 소구 유형 |
|---|---|---|
| 1 | 쫀득한 식감과 진한 감칠맛 | **감각** (맛·식감) |
| 2 | 당일작업 당일발송으로 신선함까지 | **물류** (신선도 근거) |
| 3 | 국내산 | **신뢰** (원산지) |
| 4 | 활 돌문어 | **정체** (상품명 + 상태) |
| 5 | 당일조업 / 산지직송 / 생물발송 | **증거** (공급망 3단계) |

**배지 3개가 공급망 순서 그대로다.**
잡고(조업) → 보내고(직송) → 살아서 도착(생물발송).
추상적 장점 나열이 아니라 **시간 순서**. 이게 훨씬 잘 믿긴다. ← 규칙으로 승격

**후킹 멘트 문형**
- 서브카피 1행: `[식감 형용사] + [맛 형용사]` — 명사구, 서술어 없음
- 서브카피 2행: `[공정] + [공정] + 으로 + [결과]까지!` — 느낌표 1개로 텐션
- 대제목: `[원산지] / [상태] + [상품명]` — 2줄로 끊어 덩어리 2개

### 10. 식품 법규 관점 — **전부 통과**

- 효능·기능성 표현 **없음** (면역력/피로회복/다이어트 류 0건)
- 질병 관련 표현 **없음**
- 과장 표현 없음 (최고/1위/100% 0건)
- 쓴 단어가 전부 **검증 가능한 사실**: 국내산(원산지), 활(상태), 당일조업·산지직송·생물발송(공정)
- "쫀득한 식감", "진한 감칠맛" = **관능 표현**이라 안전. 효능 아님

> **이 레퍼런스가 좋은 이유**: 금지어 하나 없이 후킹을 만들었다.
> 효능을 못 쓰는 식품에서 **공정과 상태를 팔면 된다**는 걸 보여준다. 그대로 따른다.

### 11. 가져올 것 / 버릴 것

**가져올 것**
- 4층 스택 구조 (여백 → 텍스트 → 배지 → 사진)
- 사진 40% 지배
- 제목:서브 = 4.6:1 크기비
- 단색 배경 위에만 글자 (사진 위 글자 금지)
- 원형 배지 3개 + 4글자 라벨 고정
- 배지를 블렌드 경계에 걸치기
- 포인트 컬러 없이 크기로만 대비
- 손 = 크기 자
- 공정 시간순 배지

**버릴 것 / 조건부**
- 네이비 `#000942`는 **수산물 전용**. 다른 카테고리는 톤 재선정
- 배지 3개는 상품에 검증 가능한 공정이 3개 있을 때만. 억지로 3개 못 만들면 2개로

## 히어로(`hook`) 블록 제작 규격 — REF-01에서 확정

> 앞으로 `hook` 블록은 이 표대로 만든다. 수치는 610px 캔버스 기준.

```
캔버스            610 × 1000       (1 : 1.64)
배경 상단         단색 브랜드 다크
배경 블렌드       y 485 → 575, 90px 선형 페이드
배경 하단         실물 사진 100%

상단 여백         156
서브카피          y 156, 잉크높이 16, 행 pitch 23, 최대 2줄, 가운데
간격              44
대제목            y 239, 잉크높이 73, 행 pitch 98, 2줄, 가운데
간격              50
배지 3개          y 460, 지름 137, 간격 22, 총폭 456, 좌우여백 77
  ├ 아이콘        원 상단에서 33 아래, 72×50, 흰 선 아이콘, 선굵기 3.5
  ├ 간격          14
  └ 라벨          잉크높이 15, 4글자 고정
사진 지배 영역     y 597 → 1000  (40%)

폰트              헤비 스퀘어 고딕 1종 (Black Han Sans 계열)
                  대제목 Black / 서브·라벨 한 단계 가볍게
색                다크 배경 / 배지(배경보다 더 진한 톤) / 흰 글자 / 사진 원색
포인트 컬러        없음. 대비는 크기 4.6배로만
그림자            대제목에만, opacity 30% / 0,4px / blur 12
```

**카피 슬롯 5개**
```
서브1   [식감 형용사] + [맛 형용사]              ← 관능 표현만
서브2   [공정] + [공정] + 으로 + [결과]까지!      ← 느낌표 1개
대제목1 [원산지 또는 핵심 수식어]                 ← 3~4글자
대제목2 [상태] + [상품명]                        ← 4~5글자
배지    [공정1] [공정2] [공정3]                  ← 각 4글자, 시간 순서
```

**금지**
- 사진 위에 글자 얹기
- 포인트 컬러 추가
- 배지 라벨 글자 수 불일치
- 대제목:서브카피 비율 3배 미만
- 효능·기능성 표현 (TOOL.md 5장)

## REF-02 | 상품설명1.png — 섹션 오프너 (`section-opener`)

원본 675 × 667 px · k = 0.9037 · 환산 **610 × 603** (거의 정사각 1 : 0.99)

### 1. 역할

`hook` 다음, POINT 묶음 앞에 서는 **챕터 표지**.
정보를 주지 않는다. "지금부터 중요한 얘기 나온다"는 신호만 준다.
스크롤 속도를 한 번 끊는 **속도 조절 장치**.

### 2. 구조 — 사진 전면 + 텍스트 오버레이

인트로와 정반대다. 인트로는 단색 위에만 글자를 얹었지만,
오프너는 **사진 전체에 어두운 오버레이를 깔고 그 위에 글자를 얹는다**.

```
배경        문어 다리 클로즈업 사진, 화면 100%
오버레이    검정 약 50% (측정 휘도 (70,71,75) ~ (96,55,53))
            + 얕은 심도 blur. 사진이 배경으로 후퇴
```

**규칙**: 사진 위 글자는 **오프너에서만** 허용한다. 반드시 50% 다크 오버레이 + 블러 동반.

### 3. 수치 (610 환산)

| 요소 | y | 잉크높이 | 비고 |
|---|---|---|---|

| 사진 (인셋) | 219 – 438 | 높이 **220** | — | 폭 336, 옅은 섀도 |
| 본문 1 (약속) 2줄 | 488 – 530 | **20** | `#000000` | 행 pitch 25 |
| 본문 2 (면책) 2줄 | 564 – 606 | **20** | `#828282` | 행 pitch 25 |
| 하단 여백 | 606 – 645 | — | — | 6% |

- 대제목 행 pitch **58**
- 모든 요소 중심 x = 210 / 캔버스 중심 210.5 → **완전 가운데 정렬**

### 3. 새로 발견된 규칙 3개

**① 대제목 2줄의 크기·색이 다르다**

point 블록은 2줄이 같은 크기·같은 검정이었다. 여기는 다르다.
```
1행  33px  #000000   상품명 (수식)
2행  49px  #11006F   블록 제목 (본체)
```
비율 1 : 1.5. 1행이 2행을 떠받치는 **아이브로우 역할**을 한다.
오프너의 영문 아이브로우(`CHECK POINT`)와 같은 기능, 한글판이다.

**② 사진이 풀블리드가 아니라 인셋**

```
폭      336   (캔버스의 55%)
높이    220
좌우 여백 137
비율    약 1 : 0.655  (3:2 가로형, point와 유사)
효과    옅은 드롭섀도
```

point 블록은 전부 풀블리드였다. 여기만 인셋이다.

**이유**: 포장 사진은 **흰 스티로폼 트레이**다. 풀블리드로 깔면 흰 배경과
경계가 사라져 사진이 뭉개진다. 인셋 + 섀도로 띄워야 "제품 카탈로그"로 읽힌다.

→ **규칙: 피사체 배경이 밝으면 인셋 + 섀도. 어두우면 풀블리드.**

**③ 면책 문구를 회색으로 낮춘다**

본문 1과 본문 2는 **크기가 완전히 같다(20px)**. 색만 다르다.
```
약속  #000000   신선도 유지를 위하여 충분한 아이스팩과 아이스박스에 함께 배송됩니다.
면책  #828282   추후 산지 / 업체 / 택배사 사정에 따라 택배 포장방법이 변경될 수 있습니다.
```

크기를 줄이지 않은 게 핵심이다. 줄이면 "숨기려는 것"으로 보여 분쟁 시 불리하다.
**같은 크기 + 낮은 명도** = 읽을 수는 있되 주목은 안 끄는 정직한 처리.

### 4. 메시지 구조 — 약속 → 면책

```
1  국내산 활 돌문어        ← 상품명 재확인 (스크롤 끝에서 뭘 보던 중인지 상기)
2  신선 배송안내           ← 블록 제목
3  [사진] 아이스팩 + 아이스박스 실물
4  약속: 신선도 유지를 위하여 충분한 아이스팩과 아이스박스에 함께 배송됩니다
5  면책: 산지/업체/택배사 사정에 따라 포장방법이 변경될 수 있습니다
```

**사진이 약속의 증거다.** 아이스팩이 실제로 들어간 사진을 보여주고, 바로 밑에 글로 약속한다.
글보다 사진이 먼저 온다 — 앞 블록들과 동일한 원칙.

**면책이 반드시 따라붙는다.** 신선식품은 포장 관련 클레임이 가장 많다.
약속만 하고 면책이 없으면 표시광고 분쟁에서 불리하다.

### 5. 법규

- 금지어 없음. 효능·기능성 표현 0건
- 면책 문구가 있어 구조적으로 안전
- ⚠ `충분한 아이스팩` — `충분한`은 주관적 표현. 실제 수량(예: `아이스팩 2개`)으로
  바꾸면 훨씬 강하고 분쟁 위험도 낮다

**⚠ 레퍼런스 오탈자 (따라 쓰지 말 것)**
```
✗ 변경 될 수 있습니다      →  ✓ 변경될 수 있습니다
✗ 산지 / 업체/ 택배사      →  ✓ 산지·업체·택배사   (슬래시 띄어쓰기 불규칙)
```

### 6. ⚠ 네 번째 네이비 톤 발견

```
인트로 배지        #0C035C
오프너 강조바      #04015A

package 대제목     #11006F   ← 신규
```

레퍼런스는 네이비를 **4톤**으로 흘렸다. 결정대로 `--point #00138C` 하나로 통일한다.

## 공통 패턴 추출 — REF-01~04

### 확정된 공통 규칙

**1. 폰트 1종**
전 블록이 같은 헤비 스퀘어 고딕. 잉크높이÷글자pitch ≈ 0.96~1.03.
웨이트만 바꾼다 (대제목 Black / 본문 Bold~Medium).

**2. 사진이 항상 지배한다**
| 블록 | 사진 비중 |
|---|---|
| hook | 40% |
| section-opener | 100% (오버레이) |
| point | 69% |
| package | 34% |
텍스트 비중이 25%를 넘는 블록이 없다.

**3. 사진 배치는 피사체 배경 밝기로 결정한다**
```
어두운 배경 피사체   풀블리드 (hook / opener / point)
밝은 배경 피사체     인셋 + 옅은 드롭섀도 (package)
```
텍스트는 어느 경우에도 좌우 여백 48 안에 산다.

**4. 포인트 컬러 1개, 색 총 4개**
```
다크 배경 / 포인트 블루 / 흰색 / 검정
```
빨강·노랑 없음. 강조는 **크기 대비 + 포인트 컬러 반전**으로만.

**5. 강조 형태가 역할별로 다르다**
```
원형         hook 신뢰 배지 (가운데 정렬)
각진 사각형   opener 강조 바 (가운데 정렬)
둥근 pill    point 챕터 번호 (좌측 정렬)
각진 형광펜   point 본문 하이라이트
```
형태가 곧 역할 신호다. 섞어 쓰지 않는다.

**6. 정렬이 구간별로 바뀐다**
```
hook / opener   전부 가운데   ← 몰입 구간
point           전부 왼쪽     ← 읽기 구간
package         전부 가운데   ← 안내 구간
```

**7. 명도 리듬**
다크(hook) → 다크(opener) → 라이트(point ×N) → 라이트(package)

**11. 아이브로우가 두 종류다**
```
영문 이탤릭 대문자   opener   CHECK POINT   한글의 40% 크기
한글 작은 검정       package  국내산 활 돌문어   제목의 67% 크기
```
둘 다 본체 제목을 떠받치는 같은 역할.

**12. 면책은 같은 크기, 낮은 명도**
`package` 면책 문구가 본문과 **동일한 20px**, 색만 `#828282`.
작게 쓰지 않는다. 숨기려는 것으로 보이면 분쟁 시 불리하다.

**8. 크기 대비비**
```
hook    대제목 73 : 서브 16 = 4.6 : 1   ← 때리는 구간
opener  한글 63 : 영문 25  = 2.5 : 1
point   대제목 48 : 본문 19 = 2.5 : 1   ← 읽히는 구간
```
히어로만 4.6배, 나머지는 2.5배. 일관된 두 단계.

**9. 여백 스케일 (610 환산, 실측)**
```
16  사진 → 본문
20  필 → 대제목
27  대제목 → 사진
33  본문 → 사진
48  블록 좌우 / 상단 여백
```
→ TOOL.md 여백 스케일(8/16/32/56/96/140)과 안 맞는다. **16/20/27/33/48 로 재정의 필요.**

**10. 카피 원칙**
- 존댓말 평서형 `~합니다` / `~입니다` 고정
- 대제목 2행 끝을 **상품명으로 닫아 반복 각인**
