# 예제 — 쫄깃한 담양 우렁이살

이 스킬로 실제 만든 상세페이지. 문서는 전 과정이 그대로 남아 있다.

| 파일 | 내용 |
|---|---|
| `INTERVIEW.md` | 참고 자료 입력란 · 추출된 사실 · 사진 인벤토리 26장 · 결정 기록 |
| `ANALYSIS.md` | 레퍼런스 4종 픽셀 측정 (REF-01~04) · 공통 패턴 추출 |
| `PLAN.md` | 기획안 — 블록별 y 좌표 · 카피 전문 · 법규 검사 · 합격 기준 |
| `0*.png` | 완성 블록 (가로 400px 축소판. 실제 출력은 1220px) |

## 결과

```

02_opener    610 ×  603   다크   챕터 표지

04_point2    610 × 1240   라이트 활용도
05_package   610 ×  645   라이트 소분 포장

합계 610 × 4774px
```

## 이 예제에서 볼 것

**레퍼런스를 그대로 따르지 않은 지점** — `ANALYSIS.md` 공통 패턴 절
```
네이비가 4톤으로 흩어져 있었다        → 단일 포인트 컬러로 통일
본문 상하 여백이 16/33 으로 어긋났다   → 균등하게
본문이 모바일 실효 12px 이었다        → 14px 로 상향
```

**법규 때문에 소구 축을 바꾼 과정** — `INTERVIEW.md`
```
레퍼런스 POINT 3 이 `활력 보충에 도움` `단백질이 풍부` 를 썼다
→ 기능성 표현 + 영양강조표시. 일반식품은 쓸 수 없다
→ 영양 축을 버리고 손질완료 / 활용도 2축으로 재배정
```

**사진이 2번 탈락한 기록** — `PLAN.md` 사진 배정 절
```
해상도 미달로 8장 탈락
바구니 부감컷: 테두리가 화면을 먹고 텍스트가 피사체를 가려 탈락
```
