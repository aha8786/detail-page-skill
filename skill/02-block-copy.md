# /블록카피하기

블록 레퍼런스 **1장을 분석해서 바로 PNG로 만들어 준다.**
이미 있는 상세페이지에 블록 하나를 끼워 넣고 싶을 때 쓴다.

```
/블록카피하기        분석 → 바로 렌더 → PNG 1장   ← 결과물이 목적
/상세페이지 분석하기   분석 → 구조 파일만 저장      ← 자산 등록이 목적
```

구조만 저장하고 나중에 쓸 거라면 `03-analyze.md` 로 간다.

---

## 0. 받을 것

```
필수   블록 레퍼런스 이미지 1장        "이렇게 생긴 블록"
필수   이 블록에 들어갈 내용            카피 · 사진
선택   끼워 넣을 기존 상세페이지         규격을 맞출 대상
```

내용을 안 줬으면 4단계에서 받는다. 레퍼런스만 있고 내용이 없으면 만들 수 없다.

## 1. 규격 기준 정하기

**기존 페이지에 끼워 넣는 거라 규격이 그 페이지와 같아야 한다.** 셋 중 하나로 정한다.

```
A. 기존 작업 폴더가 있다    src/base.css 와 PLAN.md 에서 캔버스·색·폰트를 읽는다
B. 프리셋 ID 를 안다        presets/<id>/PRESET.md 를 읽는다
C. 완성 PNG 만 있다         기존 PNG 를 측정해 규격을 역산한다
                           python3 scripts/measure.py 기존블록.png --target-width 610
```

사용자가 아무것도 안 주면 `presets/_index.md` 를 보여주고 고르게 한다.

**정한 규격이 이 블록의 기준이다.** 레퍼런스는 레이아웃 참고용일 뿐,
색·폰트·여백은 기존 페이지를 따른다. 안 그러면 끼워 넣었을 때 튄다.

## 2. 레퍼런스 측정

```bash
python3 scripts/measure.py ref.png --target-width <기준 캔버스 폭>
python3 scripts/measure.py ref.png --colors
```

뽑을 것:
```
요소 순서 (위→아래)
각 요소의 잉크높이 · 행 pitch · 정렬 · x 범위
요소 사이 여백
사진 영역 위치 · 크기 · 비율 · 풀블리드/인셋
강조 요소 (배지·바·필·하이라이트) 의 크기와 위치
블록 전체 높이
```

**레퍼런스에서 가져오는 것은 "배치"뿐이다.**
```
가져온다   요소 순서 · 상대 위치 · 크기 비율 · 사진 비중
안 가져온다 색 · 폰트 · 여백 스케일 → 1단계에서 정한 기준을 쓴다
```

## 3. 고정 규격으로 보정

`TOOL.md` 와 충돌하는 값은 **버리고 고친다.**

```
본문 상하 여백이 다름           → 균등하게 (라인박스 기준)
본문 모바일 실효 14px 미만      → 상향
줄 길이가 들쭉날쭉              → 의미 단위로 다시 끊음
면책을 본문보다 작게            → 같은 크기, 색만 낮춤
새로운 색이 등장                → 기준 팔레트로 치환
```

버린 값은 사용자에게 **한 줄로 알린다.** 몰래 바꾸지 않는다.

## 4. 내용 받기

```
카피      각 텍스트 슬롯에 들어갈 문구
사진      파일 경로. 없으면 어떤 컷이 필요한지 알려 준다
```

카피는 `TOOL.md` 7장 줄맞춤 규칙에 맞춰 **직접 줄을 끊는다.**
사진은 `TOOL.md` 1장 사진 선택 기준으로 판정한다. 해상도 미달이면 말한다.

카테고리를 확인하고 `TOOL.md` 6장 해당 모듈로 **이 시점에** 검사한다.
기존 페이지가 있으면 그 페이지의 카테고리를 따른다.

## 5. HTML 작성 → 렌더

기준 규격의 `base.css` 를 그대로 쓰고 블록 HTML 만 새로 쓴다.

```css
.blk{height:<측정 높이>px;background:<기준 배경색>}
.t{position:absolute;white-space:nowrap;line-height:1}
#h1{top:<잉크top − k2×font-size>px;font-size:<잉크높이 ÷ k1>px}
```

**폰트 계수를 확인한다.** 기준 폰트가 프리셋과 다르면 `k1`·`k2` 를 프로브로 다시 잰다.

```bash
./render.sh out
```

파일명은 **끼워 넣을 자리의 순번**으로 짓는다. 기존 `03_point1.png` 다음에
들어가면 `04_<이름>.png`, 뒤 블록들은 번호를 밀어야 한다. 밀 번호를 알려 준다.

## 6. 검증

```bash
python3 scripts/qa.py out/ --palette <기준 색상>
```

그리고 **PNG 를 직접 연다.**

```
기존 블록과 캔버스 폭이 같은가
기존 블록과 이어 붙였을 때 색·여백이 튀지 않는가
사진이 멘트와 맞는가
피사체가 프레임 한가운데 있는가
```

기존 블록 하나와 **세로로 이어 붙여 본다.** 이음매에서 어긋나면 고친다.

## 7. 프리셋에 저장할지 묻기 ★ 마지막

```
이 블록을 프리셋에 저장할까요?

  1. 저장  — presets/<id>/blocks/ 에 템플릿을 넣고 PRESET.md 에 좌표를 추가합니다
            다음에 같은 블록을 쓸 때 다시 분석하지 않아도 됩니다
  2. 안 함 — 이번 결과물만 쓰고 끝냅니다
```

**저장을 고르면** 하는 일:
```
presets/<id>/blocks/block-<이름>.html   템플릿 저장
presets/<id>/PRESET.md
  5장 블록 시퀀스    표에 추가
  6장 블록별 좌표    y 좌표표 + 카피 슬롯 추가
  7장 안 따른 지점   3단계에서 버린 값 기록
presets/<id>/references/ANALYSIS.md     REF-NN 으로 측정 기록 누적
presets/_index.md                        블록 시퀀스 열 갱신
```
