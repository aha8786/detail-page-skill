# /블록카피하기

**블록 한 개**를 픽셀 측정해 기존 프리셋에 추가하거나 교체한다.

```
/블록카피하기        블록 1개   → 기존 프리셋에 추가·교체
/상세페이지 분석하기   페이지 전체 → 새 프리셋 등록
```

페이지 전체를 새로 분석하는 거라면 `03-analyze.md` 로 간다.

---

## 0. 받을 것

```
블록 레퍼런스 이미지 1장
어느 프리셋에 넣을지 (기존 프리셋 ID)
이 블록이 페이지의 어느 자리인지 (첫 화면 / 중간 설명 / 마무리)
```

프리셋을 안 정했으면 `presets/_index.md` 를 보여주고 고르게 한다.

## 1. 측정

```bash
python3 scripts/measure.py ref.png --target-width <프리셋 캔버스 폭>
```

나오는 것:
```
원본 크기와 환산 배율 k
잉크 밴드 (y 시작·끝·높이)      글자 한 줄 = 한 밴드
각 밴드의 x 범위·폭·중심         가운데 정렬 여부
글자 pitch · 잉크/pitch 비율    폰트 종류 판별
행 pitch
배경색 · 다크/라이트
```

**잉크/pitch 비율로 폰트를 가린다.**
```
~0.72    일반 고딕 (Pretendard · Noto Sans KR)
0.95+    헤비 스퀘어 고딕 (Paperlogy · Black Han Sans · GmarketSans)
```

사진 영역은 `--segment` 로 경계를 잡는다.

## 2. 기록

`presets/<id>/references/ANALYSIS.md` 에 `REF-NN` 으로 **누적**한다.
기존 기록을 덮어쓰지 않는다. 예시는 `presets/hana-nongsusan/references/ANALYSIS.md`.

9항목:
```
1. 블록 판정      어느 블록 ID인가, 무슨 일을 하나
2. 전체 구조      위→아래 요소 순서, 층 비율 (사진 몇 %, 텍스트 몇 %)
3. 이미지 요소    개수·배치·비율·모서리·성격
4. 텍스트 요소    계층별 잉크높이·행 pitch·굵기·색·정렬·줄당 글자수
5. 간격           요소 사이 여백, 블록 상하 패딩, 여백 리듬
6. 색             HEX + 각 용도
7. 시선 흐름      처음 눈이 닿는 곳 → 순서 → 그 순서를 만드는 장치
8. 가져올 것 / 버릴 것
9. 법규 관점      금지 표현이 있으면 표시 (그대로 베끼지 않도록)
```

**모든 수치는 원본 px 과 프리셋 캔버스 환산값을 함께 적는다.**

## 3. 프리셋 정합성 검사

새 블록이 기존 프리셋과 어긋나는지 본다.

```
색        프리셋 팔레트 안에 있는가. 새 색이 필요하면 왜인지 적는다
폰트      프리셋과 같은 계열인가. 다르면 k1·k2 를 다시 재야 한다
여백      프리셋 여백 스케일 값을 쓰는가
정렬      프리셋 정렬 규칙(구간별)과 맞는가
강조 형태  프리셋의 형태-역할 매핑과 충돌하지 않는가
```

**어긋나면 레퍼런스가 아니라 프리셋에 맞춘다.** 레퍼런스는 참고지 기준이 아니다.

고정 규격(`TOOL.md`)과 충돌하는 값은 **버린다**. 자주 나오는 결함:
```
본문 상하 여백이 다름      → 균등하게
줄 길이가 들쭉날쭉         → 의미 단위로 다시 끊음
본문이 너무 작음           → 모바일 실효 14px 이상으로 상향
면책을 작게 숨김           → 본문과 같은 크기, 색만 낮춤
같은 색을 여러 톤으로 흘림  → 프리셋 팔레트로 통일
```

## 4. 블록 템플릿 생성

`presets/<id>/blocks/block-<이름>.html` 을 만든다. 측정한 y 좌표를 절대 배치한다.

```css
.blk{height:<측정 높이>px}
.t{position:absolute;white-space:nowrap;line-height:1}
#h1{top:<잉크top − k2×font-size>px;font-size:<잉크높이 ÷ k1>px}
```

## 5. 검증 — 원본과 숫자를 맞춘다

```bash
./render.sh out
python3 scripts/measure.py out/블록.png --target-width <프리셋 캔버스 폭>
```

잉크높이·여백·폭이 원본 측정값과 **±3px 안**에 들어오면 복제 성공.
벗어나면 `k1`·`k2` 를 다시 재고 좌표를 보정한다.

## 6. 프리셋에 등록

```
presets/<id>/PRESET.md
  5장 블록 시퀀스      새 블록을 표에 추가
  6장 블록별 좌표      y 좌표표와 카피 슬롯 추가
  9장 결정사항         언제 어느 레퍼런스에서 추가했는지 기록

presets/_index.md
  블록 시퀀스 열 갱신
```

`preview/` 에 렌더 결과 축소판을 넣어 둔다.
