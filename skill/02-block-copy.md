# /블록카피하기

남의 상세페이지 블록을 **픽셀 단위로 측정해 내 규격으로 복제**한다.
눈대중 금지. 모든 수치는 `scripts/measure.py` 로 뽑는다.

---

## 0. 받을 것

```
레퍼런스 이미지 1장 이상 (블록 단위로 잘려 있으면 가장 좋다)
이 블록이 페이지의 어느 자리인지 (첫 화면 / 중간 설명 / 마무리)
```

여러 장이면 **한 장씩** 처리한다. 3장 이상 모이면 공통 패턴을 뽑는다.

## 1. 측정

```bash
python3 scripts/measure.py 레퍼런스.png --target-width 610
```

나오는 것:
```
원본 크기와 환산 배율 k
잉크 밴드 (y 시작·끝·높이)  ← 글자 한 줄 = 한 밴드
각 밴드의 x 범위와 중심
글자 pitch (문자 advance)
배경·강조·텍스트 색 HEX
사진 영역 경계와 비율
```

**잉크 ÷ 글자pitch 비율**을 꼭 본다. 폰트 종류가 여기서 갈린다.
```
0.72 전후   일반 고딕 (Pretendard · Noto Sans KR)
0.95 이상   헤비 스퀘어 고딕 (Paperlogy · Black Han Sans · GmarketSans)
```

## 2. 기록

`references/ANALYSIS.md` 에 `REF-NN` 으로 누적한다.
`examples/woolenggi/ANALYSIS.md` 가 실제 작성 예시다.

각 레퍼런스마다 9항목:
```
1. 블록 판정      어느 블록 ID에 해당하나, 무슨 일을 하나
2. 전체 구조      위→아래 요소 순서, 층 비율 (사진 몇 %, 텍스트 몇 %)
3. 이미지 요소    개수·배치(풀블리드/인셋/그리드)·비율·모서리·성격
4. 텍스트 요소    계층별 잉크높이·행 pitch·굵기·색·정렬·줄당 글자수
5. 간격           요소 사이 여백, 블록 상하 패딩, 여백 리듬
6. 색             HEX 3~6개 + 각 용도
7. 시선 흐름      처음 눈이 닿는 곳 → 순서 → 그 순서를 만드는 장치
8. 가져올 것 / 버릴 것
9. 법규 관점      금지 표현이 있으면 표시 (그대로 베끼지 않도록)
```

**모든 수치는 원본 px 과 목표 캔버스 환산값을 함께 적는다.**
레퍼런스마다 캡처 배율이 다르므로 원본 px 은 그대로 못 쓴다.

## 3. 규격으로 승격

측정값을 `TOOL.md` 에 반영한다.

```
반복되는 값        → 토큰으로 고정 (여백 스케일·타이포 스케일)
한 번만 나온 값     → 블록 전용 규격으로 분리
레퍼런스의 결함     → 따라 하지 않는다. 결함이라고 기록한다
```

**레퍼런스를 무조건 따르지 않는다.** 자주 나오는 결함:
```
같은 색을 여러 톤으로 흘림        → 하나로 통일
본문 상하 여백이 다름             → 균등하게
줄 길이가 들쭉날쭉                → 의미 단위로 다시 끊음
본문이 너무 작음                  → 모바일 실효 14px 이상으로 상향
면책 문구를 작게 숨김             → 본문과 같은 크기, 색만 낮춤
```

## 4. 템플릿 생성

`templates/` 에 블록 HTML 을 만든다. 측정한 y 좌표를 그대로 절대 배치한다.

```css
.blk{height:<측정 높이>px}
.t{position:absolute;white-space:nowrap;line-height:1}
#h1{top:<잉크top − 0.07×font-size>px;font-size:<잉크높이 ÷ 0.87>px}
```

## 5. 검증

템플릿을 렌더하고 **원본과 같은 측정을 돌려 숫자를 맞춰 본다.**

```bash
./render.sh out
python3 scripts/measure.py out/블록.png --target-width 610
```

잉크높이·여백·폭이 원본 측정값과 ±3px 안에 들어오면 복제 성공.

## 6. 공통 패턴 추출 (3장 이상 모였을 때)

```
반복되는 블록 순서
반복되는 사진:텍스트 비율
반복되는 여백 리듬
확정할 색상 토큰
확정할 타이포 스케일
```

이게 `TOOL.md` 의 뼈대가 된다.
