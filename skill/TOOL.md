### ★ 텍스트 블록 상하 여백 균등 규칙 (v0.5 · 전 상세페이지 공통)

**본문(작은 글자) 블록은 위아래 여백을 반드시 같게 준다.**
레퍼런스는 위 16 / 아래 33으로 어긋나 있었다. 따라 하지 않는다.

여백은 **잉크가 아니라 라인박스 기준**으로 잰다.
하이라이트 띠가 라인박스 전체를 채우므로, 눈에 보이는 경계가 라인박스다.

```
계산식   여백 = (앞 요소 끝 ~ 뒤 요소 시작 간격 − 라인박스 총높이) ÷ 2

point    사진1 끝 661 → 본문 라인박스 684.5~774.5 (30×3) → 사진2 798
         위 23.5 / 아래 23.5                                    ✅ 동일

package  사진 끝 438 → 약속(25×2) → 면책(25×2) → 캔버스 645
         세 간격 전부 35.7                                      ✅ 동일
```

텍스트 그룹이 2개 이상이면 **그룹 사이 간격까지 같은 값**으로 맞춘다.

**사진 배치 — 피사체 배경 밝기로 결정한다**

```
어두운 배경 피사체   풀블리드 (좌우 여백 0)
밝은 배경 피사체     인셋 + 옅은 드롭섀도   ← 안 그러면 흰 배경과 경계가 사라진다
```

### ★ 사진 선택 기준 (v0.6 · 전 상세페이지 공통)

**우선순위대로 적용한다. 1순위를 만족하는 사진이 있으면 거기서 끝낸다.**

```
1순위  멘트 연관성
       사진과 멘트가 같이 나오는 자리는 그 멘트가 말하는 것이 찍힌 사진을 쓴다.
       "우렁이살 고르기" → 우렁이살이 보이는 컷
       "된장찌개에 넣어도"  → 된장찌개 컷
       분위기만 맞는 컷보다 내용이 맞는 컷이 항상 우선이다.

2순위  피사체 식별 가능성
       크롭·오버레이·블러를 먹인 뒤에도 무엇인지 알아볼 수 있어야 한다.
       텍스트가 피사체를 가리면 그 사진은 탈락이다.

3순위  해상도
       크롭 후 소스 폭 ≥ 1220px (DPR2 기준). 업스케일 1.4배 초과는 제외.
       단 오버레이+블러가 깔리는 자리는 1.3배까지 허용한다.

       ※ 사용자 지정 우선 — 특정 사진을 쓰라는 지시가 있으면 해상도 기준보다
         지시가 앞선다. 대신 블러·오버레이로 보완하고 실효 배율을 기록에 남긴다.

4순위  배경색 정합
       팔레트와 충돌하는 색(파랑·녹색·붉은 플라스틱 등)이 크게 잡히면 제외.
```

### ★ 크롭 중심 규칙 (v0.6 · 전 상세페이지 공통)

사진을 확대해 넣으면 반드시 잘린다. **잘리는 것 자체는 막지 않는다.
잘리더라도 상품이 프레임 한가운데 오게 맞춘다.**

```
1. 상품(주 피사체)의 시각 중심을 프레임 중심에 놓는다
2. 상품이 프레임 가장자리에 닿거나 잘려 나가면 object-position 을 조정한다
3. object-position 은 center 고정이 기본값이 아니다.
   사진마다 피사체 위치를 보고 % 값을 정한다
4. 테두리·바구니 테두리·선반 같은 배경 구조물이 화면을 먹으면
   그 사진은 그 자리에 부적합하다. 3순위로 내려가 다른 컷을 쓴다
5. 조정 후 반드시 렌더된 PNG를 열어 눈으로 확인한다
```

```css
/* 피사체 위치로 크롭 창 이동 */
object-fit: cover;
object-position: center 30%;   /* % 를 줄이면 위쪽을 보여준다 */
object-position: center 72%;   /* % 를 키우면 아래쪽을 보여준다 */

/* 프레임 가장자리의 배경 구조물을 밀어낼 때 */
transform: scale(1.34);        /* 중심에서 확대 → 사방 테두리가 잘려 나간다 */
```

**`object-position` 방향이 헷갈리면**: 값은 *소스 이미지에서 어디를 보여줄지*다.
피사체가 위쪽에 있는데 잘렸다면 **% 를 낮춘다.**

**`transform: scale`** 은 사방 테두리(박스 테두리·선반·바구니 테두리)를
한 번에 밀어낼 때만 쓴다. 실효 업스케일 배율이 그만큼 올라가므로
블러가 깔리는 자리에서만 쓰고, 배율을 기록에 남긴다.

**사진 비율**

```
포인트 사진    610 × 410   풀블리드   1 : 0.672 (약 3:2)
히어로 사진    610 × 400   풀블리드   하단 40% 영역
오프너 사진    610 × 603   풀블리드   전면 + 다크 오버레이 50%
패키지 사진    336 × 220   인셋       좌우 여백 137, 드롭섀도
```

## 2. 타이포 토큰

**폰트: 헤비 스퀘어 고딕 1종.** `Black Han Sans(검은고딕)` 계열.
페이지 전체가 이 폰트 하나. 웨이트만 바꾼다.

> 판별 근거: 레퍼런스의 잉크높이 ÷ 글자pitch = **0.96~1.03**.
> Pretendard 등 일반 고딕은 0.72. 완전히 다른 부류다.
> 렌더 시 **잉크높이(실제 글자 픽셀 높이)를 기준으로 맞춘다.** font-size 값이 아니라.

| 역할 | 잉크높이 | 행 pitch | 정렬 | 용도 |
|---|---|---|---|---|
| 히어로 대제목 | **73** | 98 | 가운데 | `hook` 전용 |
| 오프너 한글 | **63** | 90 | 가운데 | `section-opener` |
| 포인트 대제목 | **48** | 64 | 왼쪽 | `point` |
| 본문 | **22** | 30 | 왼쪽 | `point` 설명문 ★v0.2 상향 |
| 히어로 서브카피 | **16** | 23 | 가운데 | `hook` |
| 배지 라벨 | **15** | — | 가운데 | `hook` 원형 배지 |
| 패키지 제목 | **49** | 58 | 가운데 | `package` 2행 |
| 패키지 아이브로우 | **33** | — | 가운데 | `package` 1행 (상품명) |
| 안내 본문 | **20** | 25 | 가운데 | `package` 약속·면책 |
| 영문 아이브로우 | **25** | — | 가운데 | `section-opener` 이탤릭 |
| 필 글자 | **16** | — | 가운데 | `point` POINT N |

**크기 대비비 (지켜야 할 최소값)**

```
hook     대제목 73 : 서브 16 = 4.6 : 1    ← 때리는 구간. 3:1 미만이면 후킹 실패
opener   한글 63 : 영문 25  = 2.5 : 1
point    대제목 48 : 본문 22 = 2.2 : 1    ← 읽히는 구간. 2:1 미만 금지
package  제목 49 : 본문 20  = 2.45 : 1
```

**아이브로우 2종** — 본체 제목을 떠받치는 같은 역할
```
영문 이탤릭 대문자   opener    CHECK POINT        한글의 40%
한글 작은 검정       package   국내산 활 돌문어     제목의 67%
```

**본문 22px 결정 근거** (v0.2)
레퍼런스는 19px. 모바일 실효 12px로 작다. 22px로 올리면 실효 14px.
행 pitch도 26 → 30으로 비례 상향(비율 1.37 유지). 밀도감은 거의 유지된다.

**줄 수 고정 규칙**
```
hook   서브카피 2줄 / 대제목 2줄
point  대제목 반드시 2줄 (1줄·3줄 금지) / 본문 2~4줄 (5줄 이상 금지)
opener 한글 3줄
```

## 3. 색상 토큰 (확정 — v0.5 팔레트 교체)

```
--charcoal   #292929   다크 블록 배경 · 라이트 블록 텍스트 · 필/하이라이트 배경
--cream      #F5F0E6   라이트 블록 배경 · 다크 블록 텍스트 · 배지 필 · 반전 글자
--warmgray   #8C867C   아이브로우 · 면책 전용
--overlay    rgba(0,0,0,.55)   오프너 사진 오버레이
```

**색은 이 3개가 전부다.** 파랑·빨강·노랑 0개.
강조는 **크기 대비 + 차콜/크림 반전**으로만 만든다.

**블록별 적용**

| 블록 | 배경 | 텍스트 | 강조 요소 |
|---|---|---|---|
| `hook` | 차콜 | 크림 | 배지 = 크림 필 + 차콜 글자 |
| `section-opener` | 사진 + 오버레이 | 크림 | 강조바 = 크림 배경 + 차콜 글자 |
| `point` | 크림 | 차콜 | 필·하이라이트 = 차콜 배경 + 크림 글자 |
| `package` | 크림 | 차콜 | 아이브로우·면책 = 웜그레이 |

**면책 문구는 `--warmgray`, 크기는 본문과 동일하게.**
작게 쓰면 숨기려는 것으로 보여 분쟁 시 불리하다.

### 3-1. 다크 블록 배지 — 입체 스펙

레퍼런스는 배경보다 진하게 눌렀지만, 우리는 **크림으로 튀어나오게** 만든다.

```css
background: linear-gradient(180deg,#FFFDF7 0%,#F5F0E6 42%,#DED5C0 100%);
border: 1px solid rgba(255,255,255,.55);
box-shadow:
  0 14px 26px rgba(0,0,0,.50),        /* 바깥 그림자 — 띄움 */
  0 4px 8px  rgba(0,0,0,.34),         /* 접지 그림자 */
  inset 0 3px 4px  rgba(255,255,255,.98),   /* 상단 하이라이트 */
  inset 0 -5px 9px rgba(120,104,76,.30),    /* 하단 안쪽 그늘 */
  inset 0 0 0 1px  rgba(255,255,255,.35);   /* 안쪽 림 */
```

아이콘·라벨은 `--charcoal` 선.

### 3-2. 다크 → 사진 블렌드

단색 배경이 사진으로 넘어가는 자리는 **페이드 200px + 비네트**를 함께 쓴다.
페이드만 쓰면 사진 상단이 밝을 때 경계선이 드러난다.

```css
/* 페이드 */
linear-gradient(180deg,#292929 0%,rgba(41,41,41,.88) 28%,
                rgba(41,41,41,.55) 55%,rgba(41,41,41,.22) 78%,rgba(41,41,41,0) 100%)
/* 비네트 (사진 전체에 겹침) */
radial-gradient(120% 78% at 50% 62%,rgba(41,41,41,0) 42%,rgba(41,41,41,.38) 100%)
```

### 3-3. 밝은 배경 사진

크림 배경 위에 흰 배경 사진을 얹으면 하얗게 뜬다.
**1px `rgba(41,41,41,.10)` 테두리**를 둘러 경계를 만든다.

## 4. 강조 형태 — 역할별로 다르다. 섞지 않는다

| 형태 | 블록 | 정렬 | 역할 |
|---|---|---|---|
| **원형** 배지 | `hook` | 가운데 | 신뢰 요소 3개 |
| **각진 사각형** 바 | `section-opener` | 가운데 | 선언·강조 |
| **둥근 pill** | `point` | 왼쪽 | 챕터 번호 |
| **각진 형광펜** | `point` 본문 | — | 사실 강조 |

**정렬 규칙**
```
hook / section-opener   전부 가운데   ← 몰입 구간
point                   전부 왼쪽     ← 읽기 구간
package / notice        전부 가운데   ← 안내 구간
```

**명도 리듬**
```
hook(다크) → opener(다크) → point ×N(라이트) → package(라이트)
```

### 5-2. 선택 블록 — 요청이 있을 때만 만든다

아래 블록은 **기본 세트에 포함하지 않는다.** 만들라는 지시가 있을 때만 추가한다.

| ID | 이름 | 상태 |

| `notice` | 상품정보제공고시 | 레퍼런스 없음 |
| `howto` | 조리법·손질법 | 레퍼런스 없음 |
| `trust` | 인증·수상·생산시설 | 레퍼런스 없음 |
| `review` | 구매 후기 | 레퍼런스 없음 |
| `faq` | 자주 묻는 질문 | 레퍼런스 없음 |

> **플랫폼이 대신 처리하는 것 — 상세 이미지에 넣지 않는다**
>
> 아래는 네이버 스마트스토어·쿠팡·카페24가 **자체 입력 폼**으로 받아 페이지에
> 따로 표시한다. 상세 이미지 안에 중복해서 넣지 않는다.
>
> ```
> 상품정보제공고시      플랫폼 폼에 입력 → 법적 의무 충족
> 배송비·배송 소요일    플랫폼 배송 설정
> 택배사               플랫폼 배송 설정
> 제주·도서 추가배송비   플랫폼 배송 설정
> 교환·반품·환불 안내   플랫폼 정책 영역
> 유통기한             상품정보제공고시 항목
> ```
>
> 플랫폼 폼은 반드시 채워야 한다. 이미지 제작 범위 밖의 일이다.

### 5-3. 선택 블록 추가 절차

선택 블록을 만들 때는 **레퍼런스 이미지를 받아 분석한 뒤** 규격을 확정한다.
추측으로 설계하지 않는다.

```
1. 레퍼런스 이미지 수령
2. 픽셀 스캔 측정 (잉크 박스 / 여백 / 색 / 사진 비율)
3. references/ANALYSIS.md 에 REF-NN 으로 기록
4. TOOL.md 5-1 표에 블록 추가 + 캔버스 높이 확정
5. 공통 패턴과 충돌하면 공통 패턴 쪽을 갱신
```

**레퍼런스 없이 만들라고 하면**: `package` 스타일(가운데 정렬 / 라이트 배경 /
아이브로우 + 제목 / 본문 + 면책)을 확장해서 설계하고, 그 사실을 명시한다.

### 6-9. 포장 안내 (`package`) — 쓰지 않는 것

**① 배송·물류 관련은 전부 이미지에서 뺀다**

플랫폼이 자체 폼으로 표시하므로 중복이고, 바뀌면 이미지를 다시 뽑아야 한다.

```
✗ 택배사명 (CJ대한통운 / 로젠 등)     ✗ 배송 소요일 (1~2일 등)
✗ 아이스박스 / 스티로폼 박스 규격       ✗ 아이스팩 개수
✗ 제주·도서 추가배송비                ✗ 배송비 / 무료배송 조건
✗ 주문 마감 시각 / 발송 요일           ✗ 교환·반품·환불 조건
✗ 유통기한 / 소비기한
```

**② `package` 블록에 남는 것**

```
✓ 포장 형태        200g 소포장 / 진공 포장
✓ 보관 온도        냉동 보관
✓ 사용 방법        해동 후 바로 사용
✓ 면책 문구        포장 변경 가능성
```

**③ 약속 뒤에 면책을 붙인다**
```
약속  200g씩 소분해 진공 포장 후 냉동 상태로 보내드립니다.    #000000
면책  수급 사정에 따라 포장 방법이 변경될 수 있습니다.        #828282
```
약속만 하고 면책이 없으면 표시광고 분쟁에서 불리하다.
**면책 문구에 택배사를 쓰지 않는다.** `수급 사정` / `원물 사정` 으로 쓴다.

**④ 주관적 수량 표현 금지**
```
✗ 충분한 / 넉넉한 / 두툼한 포장   →  ✓ 200g 소포장 (실제 수치)
```

**⑤ 면책을 작게 쓰지 않는다** — 본문과 같은 크기, 색만 `--notice`.

### 6-10. 영양 소구 순화 규칙 ★v0.2 신설

POINT에서 영양 축을 쓰기로 했다. **표현만 순화해서** 간다.

**① 영양강조표시 용어 전면 금지**

「식품등의 표시기준」상 아래 단어는 기준치 충족 + 시험성적서가 있어야 쓴다. 안 쓴다.
```
풍부   가득   많이 함유   고(高)단백   저(低)지방   듬뿍
급원   높은   강화   보충
```
> 기준: `풍부/많이` = 1일 영양성분 기준치의 **15% 이상**, `함유/급원` = **7.5% 이상**

**② 기능성 연결어 전면 금지**
```
~에 도움이 되며        ~에 좋은         ~을 보충
~에 유익한            ~을 채워주는      ~에 필요한
```

**③ 허용되는 영양 서술 — 3가지만**

| 방식 | 예시 | 조건 |
|---|---|---|
| 성분명 단순 언급 | `타우린이 들어 있는 돌문어` | 강조어·기능 연결 없이 |
| 수치 + 출처 병기 | `단백질 15.5g / 100g (출처: 국가표준식품성분표)` | 출처를 같은 화면에 |
| 관능·물성 서술 | `기름기 적은 담백한 흰 살` | 사실인 물성 |

**④ 대제목 대체 문형**
```
✗  몸에도 최고! / 영양 가득한 돌문어
✓  기름기 적은 / 담백한 흰 살 돌문어
✓  숫자로 보는 / 돌문어 영양성분
✓  타우린이 들어 있는 / 국내산 돌문어
```

**⑤ 본문 대체 문형**
```
✗  타우린을 함유하고 있어 활력 보충에 도움이 되며, 단백질이 풍부하고
    철분과 각종 미네랄도 함유하고 있어 건강한 식단으로 즐기기 좋습니다.

✓  돌문어에는 타우린과 단백질이 들어 있습니다. 기름기가 적고 담백해
    구이·숙회·볶음 어디에 써도 잘 어울립니다.
   (수치를 쓸 경우 → 100g당 단백질 15.5g · 출처: 국가표준식품성분표 를 같은 줄에)
```

### ★ 본문 줄맞춤 규칙 (v0.5 · 전 상세페이지 공통)

본문은 자동 줄바꿈에 맡기지 않는다. **줄을 직접 끊어 쓴다.**

```
1. 한 줄 = 완결된 구 또는 문장. 어절 중간에서 끊지 않는다
2. 한 줄 안에서 문장이 끝나고 새 문장이 시작되게 하지 않는다
3. 줄 간 글자 수 차이 3자 이내. 가능하면 전부 같은 글자 수
4. 최장 줄이 콘텐츠 폭(514px)을 넘지 않는다
5. 쉼표는 줄 끝에 두지 않는다. 다음 줄로 넘긴다
6. 하이라이트는 각 줄 앞머리에 배치해 왼쪽으로 세로 정렬시킨다
```

**우선순위**: 1·2번(의미 단위)이 3번(길이 균등)보다 **항상 우선**이다.
충돌하면 의미 단위를 지키고 길이 차이를 감수한다.
문장을 쪼개 길이를 맞추면 읽는 흐름이 끊겨 손해가 더 크다.

**줄 수는 고정값이 아니다.** 내용에 맞춰 2~4줄로 쓰고,
블록 높이를 그에 맞게 조정한다 (본문 1줄 = 라인박스 30px).

**나쁜 예 — 어절이 줄을 넘어간다**
```
국내산(담양) 우렁이를 껍질 벗기고 삶는     (19자)
것까지 마쳤습니다. 다른 것은 넣지 않고     (19자)
삶기만 했습니다. 해동 후 바로 쓰세요.      (18자)
```

**좋은 예 — 세 줄 모두 완결 + 글자 수 동일**
```
껍질 벗기고 삶는 것까지 마쳤습니다.       (18자)
다른 것은 넣지 않고 삶기만 했습니다.      (18자)
해동 후 바로 요리에 넣으시면 됩니다.      (18자)
```

## 10. 자체 테스트 체크리스트

렌더된 PNG를 **직접 열어** 확인한다. 코드만 보고 통과시키지 않는다.

**규격**
- [ ] 폭 정확히 1220px (610 × DPR2)
- [ ] 모든 블록 높이 3000px 이하
- [ ] 블록 이어붙였을 때 이음매 색 어긋남 없음
- [ ] 좌우 여백 48px 일정 / 사진만 풀블리드
- [ ] 포인트 사진 비율 1 : 0.672

**타이포**
- [ ] 본문 잉크높이 22px
- [ ] 폰트 폴백 없음 (Black Han Sans 계열 적용 확인)
- [ ] `point` 대제목 정확히 2줄
- [ ] `point` 본문 3줄 이하
- [ ] 크기 대비비 — hook 3:1 이상 / point 2:1 이상
- [ ] 줄바꿈이 단어 중간을 끊지 않음

**사진 (v0.6)**
- [ ] 멘트가 함께 나오는 사진이 **그 멘트의 내용과 일치**하는가
- [ ] 크롭·오버레이·블러 후에도 피사체가 **무엇인지 알아볼 수 있는가**
- [ ] 텍스트가 피사체를 가리지 않는가
- [ ] **상품이 프레임 한가운데 있는가.** 가장자리에 걸리거나 잘려 나가지 않았는가
- [ ] 배경 구조물(테두리·선반·바구니 테두리)이 화면을 먹지 않는가
- [ ] 크롭 후 소스 폭 ≥ 1220px (블러 자리는 ≥ 940px)
      사용자 지정 사진이라 기준을 넘겼다면 **실효 배율을 기록에 남겼는가**
- [ ] 팔레트와 충돌하는 색이 크게 잡히지 않는가
- [ ] **렌더된 PNG를 직접 열어 위 7개를 눈으로 확인했는가**

**여백·줄맞춤 (v0.5)**
- [ ] 본문 블록 상하 여백이 **정확히 동일** (라인박스 기준)
- [ ] 텍스트 그룹이 2개 이상이면 그룹 사이 간격까지 동일
- [ ] 본문 각 줄이 완결된 구·문장. 어절 중간 끊김 0건
- [ ] 줄 간 글자 수 차이 3자 이내
- [ ] 줄 끝에 쉼표 0건
- [ ] 한 줄 안에서 문장이 끝나고 새 문장이 시작되지 않는가

**색·형태**
- [ ] 차콜 `#292929` · 크림 `#F5F0E6` · 웜그레이 `#8C867C` 외 색 혼입 없음
