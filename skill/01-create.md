# /상세페이지 만들기

`TOOL.md` 를 먼저 읽는다. 아래 7단계를 순서대로 밟는다. 단계를 건너뛰지 않는다.

---

## 0. 범위 확정

```
플랫폼       네이버 스마트스토어 / 쿠팡 / 카페24 / 자사몰
카테고리     식품 / 화장품 / 패션 / 가전 …
캔버스 폭     기본 610px. 플랫폼이 다르면 사용자에게 확인
출력 방식     블록별 개별 PNG (기본) / 한 장 통짜
```

**식품이면** `TOOL.md` 6장(광고 금지 표현)을 이 시점에 통째로 읽는다.

## 1. 레퍼런스 분석

레퍼런스 이미지가 있으면 `/블록카피하기`(`02-block-copy.md`)로 먼저 규격을 뽑는다.
없으면 `TOOL.md` 기본 규격으로 간다.

## 2. 인터뷰

**사실만 받는다.** 추측으로 채우지 않는다. 모르는 항목은 "모름"으로 두고 카피에서 뺀다.

```
상품    정확한 상품명 · 원산지 · 중량/수량 옵션 · 가격
공정    만드는 과정과 순서 (배지 3개의 재료가 된다)
상태    손질 범위 · 보관 온도 · 받는 시점의 상태
소재    사진 폴더 경로 · 인증서 · 시험성적서 · 기존 카피
```

참고 자료(판매글·경쟁사 링크·인증서)를 받으면 `INTERVIEW.md` 의 **참고 자료 입력란**에
그대로 붙여 넣고, 거기서 사실을 추출해 표로 정리한다.

**묻지 않는 것** — 플랫폼 입력 폼이 처리한다 (`TOOL.md` 6-9절)
```
택배사 · 배송 소요일 · 아이스박스 · 아이스팩 개수 · 제주도서 · 유통기한 · 교환반품
```

## 3. 사진 인벤토리

사진 폴더를 받으면 **전부 훑어보고** 분류한다. 컨택트시트를 만들어 한 번에 본다.

```
원물·벌크 / 손 스케일컷 / 포장·소분 / 조리·활용 / 공정
```

각 사진의 **크롭 후 사용 가능 폭**을 계산한다 (`TOOL.md` 1장 사진 선택 기준).

```python
cw = min(w, int(h / 목표비율))      # 목표비율 = 높이÷폭
배율 = (캔버스폭 × DPR) / cw        # 1.4 초과면 제외
```

필요 장수를 알린다. 기본 5블록이면 **최소 7장**.

## 4. 블록 선택 + 소구 축 배정

```
hook            필수
section-opener  선택
point ×2~3      필수. 축이 서로 겹치면 안 된다
package         필수
```

**소구 축**은 보유 사진과 인터뷰 사실에서 나온다. 증거 사진이 없는 축은 쓰지 않는다.

## 5. 기획안

`examples/woolenggi/PLAN.md` 를 형식 참고로 쓴다. 반드시 담을 것:

```
블록별 y 좌표표 (여백까지 숫자로)
카피 전문 + 줄 폭 검산
사진 배정 + 멘트 연관성 + 크롭 object-position
법규 검사 결과 (항목별 건수)
합격 기준 — 전부 수치로
```

**합격 기준을 수치로 못 쓰면 기획이 덜 된 것이다.** 7단계에서 채점이 안 된다.

## 6. HTML/CSS → 렌더

`templates/` 를 복사해 시작한다.

```
base.css           토큰 (색·폰트·여백)
point.css          point 블록 공통
block-*.html       블록별 레이아웃
render.sh          headless Chrome 렌더
```

**텍스트 위치 계산** — 폰트마다 다르므로 먼저 프로브 렌더로 두 계수를 잰다.

```
잉크높이 = font-size × k1        (Paperlogy k1 ≈ 0.87)
잉크 top = span top + k2 × font-size   (line-height:1 일 때 k2 ≈ 0.07)

→ font-size = 목표잉크 ÷ k1
→ span top  = 목표잉크top − k2 × font-size
```

하이라이트가 붙는 본문은 각 줄을 `display:inline-block; height:행pitch; line-height:행pitch`
로 두고 라인박스째 배치한다. 그래야 띠 높이가 행간과 정확히 맞는다.

렌더:
```bash
./render.sh out        # 610px · DPR2 → 1220px 폭 PNG
```

## 7. 자체 테스트

```bash
python3 scripts/qa.py out
```

**그리고 PNG를 직접 연다.** 스크립트가 못 잡는 것들이 있다.

```
사진이 멘트와 맞는가
피사체가 프레임 한가운데 있는가
텍스트가 피사체를 가리지 않는가
배경 구조물(테두리·선반)이 화면을 먹지 않는가
```

`TOOL.md` 10장 체크리스트를 전수 대조한다. 실패 항목은 고치고 그 블록만 다시 렌더한다.
