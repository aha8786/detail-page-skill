# 프리셋 — 하나농수산형 (`hana-nongsusan`)

레퍼런스 4종(`references/ANALYSIS.md` REF-01~04)을 픽셀 측정해 뽑은 블록 구조.
수산물·신선식품에 맞춰 **증거 사진을 크게 쓰고 글은 적게 쓰는** 구성.

`skill/TOOL.md`(고정 규격)와 함께 읽는다. 충돌하면 고정 규격이 이긴다.

## 1. 레이아웃

```
좌우 여백     48      (콘텐츠 폭 514)
사진          610 풀블리드 — 단, 밝은 배경 피사체는 인셋 + 1px 웜 테두리
```

**여백 스케일** (실측값. 이 값만 쓴다)
```
s1   16    사진 → 본문
s2   20    필·배지 → 대제목
s3   27    대제목 → 사진
s5   48    블록 좌우 · 블록 상단
s6   90    큰 섹션 분리
s7  155    히어로·오프너 상단
```

**본문 블록 상하 여백은 반드시 같게 준다** (고정 규격).
```
point     사진1 끝 → 본문 라인박스 → 사진2      위 23.5 / 아래 23.5
package   사진 끝 → 약속 → 면책 → 캔버스 끝      세 간격 전부 35.7
```

## 2. 타이포

**폰트: Paperlogy 1종.** 웨이트만 바꾼다.
```
대제목·제목   Paperlogy-9Black
서브·라벨·필  Paperlogy-7Bold
본문          Paperlogy-6SemiBold
면책          Paperlogy-5Medium
```

**배치 계수** (렌더 프로브로 실측)
```
k1 = 0.87     잉크높이 = font-size × k1
k2 = 0.07     잉크 top = span top + k2 × font-size     (line-height:1 기준)

font-size = 목표잉크 ÷ 0.87
span top  = 목표잉크top − 0.07 × font-size
```

| 역할 | 잉크높이 | 행 pitch | 정렬 | 쓰이는 곳 |
|---|---|---|---|---|
| 히어로 대제목 | 73 | 98 | 가운데 | hook |
| 오프너 한글 | 63 | 90 | 가운데 | opener |
| 포인트 대제목 | 48 | 64 | 왼쪽 | point |
| 패키지 제목 | 49 | 58 | 가운데 | package |
| 패키지 아이브로우 | 33 | — | 가운데 | package |
| 본문 | 22 | 30 | 왼쪽 | point |
| 안내 본문 | 20 | 25 | 가운데 | package |
| 히어로 서브카피 | 16 | 23 | 가운데 | hook |
| 필 글자 | 16 | — | 가운데 | point |
| 배지 라벨 | 15 | — | 가운데 | hook |
| 영문 아이브로우 | 25 | — | 가운데 | opener |

**대비비**
```
hook      73 : 16 = 4.6 : 1     때리는 구간
opener    63 : 25 = 2.5 : 1
point     48 : 22 = 2.2 : 1     읽히는 구간
package   49 : 20 = 2.45 : 1
```

## 3. 색

```
--charcoal   #292929   다크 배경 · 라이트 블록 텍스트 · 필·하이라이트 배경
--cream      #F5F0E6   라이트 배경 · 다크 블록 텍스트 · 배지 필 · 반전 글자
--warmgray   #8C867C   아이브로우 · 면책 전용
--overlay    rgba(0,0,0,.55)
```

**색 3개가 전부.** 파랑·빨강·노랑 0개. 강조는 크기 대비 + 차콜/크림 반전으로만.

**명도 리듬**
```
hook(다크) → opener(다크) → point ×N(라이트) → package(라이트)
```

**정렬**
```
hook · opener · package   가운데
point                      왼쪽
```

## 4. 강조 형태 — 역할별로 다르다. 섞지 않는다

| 형태 | 블록 | 스펙 |
|---|---|---|
| 원형 입체 배지 | hook | 지름 137 · 간격 22 · 크림 그라데이션 + 4중 그림자 |
| 각진 사각형 바 | opener | 높이 91 · 좌우패딩 17 · radius 0 · 크림 배경 |
| 둥근 pill | point | 106 × 36 · radius 18 · 좌측정렬 x48 |
| 각진 형광펜 | point 본문 | 높이 = 행 pitch(30) · 좌우패딩 5 · radius 0 |

**배지 입체 CSS**
```css
background: linear-gradient(180deg,#FFFDF7 0%,#F5F0E6 42%,#DED5C0 100%);
border: 1px solid rgba(255,255,255,.55);
box-shadow:
  0 14px 26px rgba(0,0,0,.50),
  0 4px 8px  rgba(0,0,0,.34),
  inset 0 3px 4px  rgba(255,255,255,.98),
  inset 0 -5px 9px rgba(120,104,76,.30),
  inset 0 0 0 1px  rgba(255,255,255,.35);
```

**다크 → 사진 블렌드** (페이드만 쓰면 사진 상단이 밝을 때 경계가 드러난다)
```css
/* 페이드 200px */
linear-gradient(180deg,#292929 0%,rgba(41,41,41,.88) 28%,
                rgba(41,41,41,.55) 55%,rgba(41,41,41,.22) 78%,rgba(41,41,41,0) 100%)
/* 비네트 — 사진 전체에 겹침 */
radial-gradient(120% 78% at 50% 62%,rgba(41,41,41,0) 42%,rgba(41,41,41,.38) 100%)
```

## 7. 이 프리셋이 레퍼런스를 따르지 않은 지점

레퍼런스를 그대로 베끼지 않았다. 아래는 의도적 수정이다.

| 레퍼런스 | 이 프리셋 | 이유 |
|---|---|---|
| 네이비 4톤 (`#0C035C`/`#04015A`/`#00138C`/`#11006F`) | 단일 포인트 컬러 | 톤 분열은 결함 |
| 본문 상하 여백 16 / 33 | 균등 | 어긋나 보임 |
| 본문 잉크 19 (모바일 실효 12px) | 22 (실효 14px) | 가독성 |
| 면책을 본문보다 작게 | 같은 크기, 색만 낮춤 | 분쟁 시 불리 |
| 줄 길이 들쭉날쭉 | 의미 단위로 다시 끊음 | 가독성 |
