# 프리셋 카탈로그

하나의 프리셋 = **하나의 상세페이지 블록 구조 세트**.
레퍼런스를 분석해 뽑아낸 레이아웃·색·타이포·블록 시퀀스가 한 묶음으로 들어 있다.

`/상세페이지 만들기` 1단계에서 여기서 고른다.
새 프리셋은 `/상세페이지 분석하기` 로 등록한다.
`/블록카피하기` 와 `/알아서 만들기` 는 마지막에 "프리셋에 저장할까요?" 를 물어 여기에 보탠다.

**프리셋이 하나도 없으면** `/상세페이지 만들기` 대신 `/알아서 만들기` 를 권한다.
구조까지 설계해서 만들고, 끝나면 그 결과를 프리셋으로 저장할 수 있다.

## 프리셋 선택 UI

`/상세페이지 만들기` 를 고르면 이 표를 읽어 아래처럼 보여준다.

```
어떤 블록 구조로 만들까요?

  1. hana-nongsusan   하나농수산형
     다크 히어로 → 라이트 정보 구간. 사진 비중 69%
     hook → opener → point ×2~3 → package
     수산물 · 신선식품 · 가공식품

  2. 새 구조 만들기
     레퍼런스 페이지가 있으면 /상세페이지 분석하기 로 먼저 프리셋을 등록합니다

번호로 골라 주세요.
```

프리셋이 2개 이상이면 전부 나열한다. 사용자가 상품 카테고리를 이미 말했으면
**맞는 카테고리** 열로 걸러 추천을 먼저 보여주되, 나머지도 함께 보여준다.

## 프리셋 폴더 규약

```
presets/<id>/
  PRESET.md                 이 프리셋의 전체 규격 (필수)
  blocks/                   블록 HTML·CSS·render.sh (필수)
    base.css
    point.css
    block-*.html
    render.sh
  references/ANALYSIS.md    측정 근거 — 어느 레퍼런스에서 어떻게 뽑았는지 (필수)
  preview/*.png             미리보기 축소판 (선택)
```

`PRESET.md` 가 없는 폴더는 프리셋으로 치지 않는다.

---

## 고정 규격 vs 프리셋

```
skill/TOOL.md       고정 규격 — 프리셋이 바뀌어도 항상 적용
                    여백 균등 · 줄맞춤 · 사진 선택 · 크롭 중심 · 대비비 하한
                    식품 광고 법규 (카테고리 모듈)

presets/<id>/       프리셋 — 고를 때마다 바뀜
PRESET.md           캔버스 폭 · 색상 · 폰트 · 타이포 수치 · 블록 y 좌표 · 시퀀스
```

**충돌하면 고정 규격이 이긴다.** 프리셋이 "본문 상하 여백을 다르게" 같은 값을
들고 와도 적용하지 않는다. 그건 레퍼런스의 결함이지 규격이 아니다.
